# Key Stakeholders & User Personas

- Persona 1 — Refinery Engineer

# Typical request:
- “Review this inspection report and equipment photograph. Compare the finding with our maintenance SOP and draft an approval note for corrective action.”

# Needs:
PDF/image understanding
internal SOP search
citations
structured recommendations
DOCX output

# Persona 2 — Software / Automation Engineer
- Typical request: “Read this Python maintenance script, find why the CSV output is wrong, fix it and run the tests.”

# Needs:
- code reasoning
- filesystem access
- sandbox execution
- iterative debugging
- verification

# Persona 3 — Procurement / Finance Officer
- Typical request: “Compare these three vendor quotations against the tender requirement and create a recommendation spreadsheet.”

# Needs:
- PDF/table extraction
- calculations
- spreadsheet creation
- organization policy retrieval

# Persona 4 — Management / Approval Authority
- Typical request: “Summarize this inspection report and prepare a one-page approval note with cost and risk justification.”

# Needs:
concise summaries
auditability
citations
real deliverables
confidentiality assurance

# Persona 5 — IT / CISO / AI Platform Administrator

# Needs:
offline deployment
model registry
access control
audit logs
tool permission policies
network isolation
model health
resource monitoring
